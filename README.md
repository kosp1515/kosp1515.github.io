# Nikos Kospanos — Portfolio

Static website (HTML, CSS, JavaScript). Open `index.html` directly in a browser.

## Structure

```
index.html          Home
portfolio.html      Projects
photography.html    Photography (with lightbox)
about.html          About (education, experience)
contact.html        Contact (EmailJS form)
assets/
  css/style.css     One shared stylesheet for every page
  js/main.js        Mobile menu, footer year
  js/gallery.js     Photo lightbox
  js/contact.js     Form validation and sending
  favicon.svg
  files/           Photos and CV
```
